SRAM read/write demo (VHDL, DE2 board)

Writes and reads 8-bit values to the external SRAM on the Altera DE2 board using the switches. SW15–11 select one of 32 addresses, SW7–0 set the data, and SW17 controls write (0) or read (1). The seven-segment displays show the address on HEX7–6, the input data on HEX5–4, and the data read from SRAM on HEX1–0.
